Practice · Agentic Delivery

How I Build & Coach Teams

After completing the Diffusion.io agentic development boot camp, I changed how I ship my own products and how I coach PMs and engineers at ABC Fitness. Moving beyond ad-hoc chat prompts means treating agents like real delivery teams: explicit contracts, isolated ownership, and deterministic checks before anything lands.

The point is not generating code faster—it is raising the bar on clarity. When a product spec defines exact boundaries and verifiable acceptance criteria, agentic loops ship cleaner software and free people to focus on architecture and judgment.

Spec before code
Define the data contract, file ownership, and acceptance criteria before asking an agent to write implementation code.
Bounded slices
Split work into small, non-overlapping tasks so parallel agents never step on each other and diffs stay readable.
Deterministic verification
Pair generation with automated tests, layout assertions, and link checks rather than trusting visual spot-checks alone.
Team habits over heroics
Coach PMs and engineers on repeatable sprint workflows they can run together every week instead of isolated prompt tricks.
