How I build

AI-assisted delivery, with product judgment in the loop

I use agents for focused research, implementation and critique. I set the intent, constraints and interfaces, then integrate the work and decide what is ready to ship. Useful evidence matters more than an impressive-sounding metric or a green check on its own.

  1. Choose the decision. Start with the user or business need the work should resolve.
  2. Scope the work. Give each lane a clear owner, a small boundary and shared contracts.
  3. Build and critique. Use agents to move bounded work forward and challenge the result.
  4. Integrate deliberately. Review the actual changes, preserve unrelated work and close the gaps between lanes.
  5. Verify what matters. Check behavior, content, links and release conditions against the original intent.
  6. Learn from release. Stage changes where appropriate, then use real feedback to choose the next step.

The customer product and the way I build it are separate things. For example, DocketStamp uses deterministic templates for letter content; a person reviews and signs the document. AI agents help me develop and inspect the software, not make legal promises on the product’s behalf.
